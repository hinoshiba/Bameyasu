# Security Policy

## Supported versions

Only the latest App Store release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or privacy leak. Use GitHub's private vulnerability reporting for this repository. Include the affected version, device/iOS version, reproduction steps, impact, and a minimal proof of concept without real user data.

The maintainer should acknowledge reports within seven days, provide status at least every 14 days while investigating, coordinate disclosure, and credit the reporter if requested and appropriate.

Never attach captured images, audio, personal data, signing credentials, provisioning profiles, or App Store Connect keys to a public issue.
